Accuracy table and figure

The combined method and checked refineR use method=A and method=C on the stratum=pathology rows in accuracy.csv. The return percentage divides the number reported by the number assigned. The average error, returned_error, uses only datasets with intervals. Percentages are rounded to one decimal except exact 100%; errors are rounded to three decimals.

Unchecked refineR uses the arm=baseline rows and native_lower, native_upper, native_z_lower, and native_z_upper fields from these exports:

  • Confirmation baseline fits and index and SHA-256 manifest.
  • RIbench smaller-dataset baseline fits and SHA-256 manifest.
  • RIbench 50,000-result baseline fits and SHA-256 manifest.

The baseline rows match the published input index by dataset ID and the hashes of the routine and screened results. Count an interval when all requested limits are finite. For each returned interval, take the absolute native z deviation, cap it at 5 per requested limit, and average across the requested limits. Use the signed native z deviations as exported, including the RIbench upper-zero convention. Average those case errors for each size and share-of-patients group. The confirmation scores also match the archived scoring on all 6,062 datasets where checked refineR returned an interval.
