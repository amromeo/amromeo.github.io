anchoredRI

anchoredRI estimates a laboratory reference interval from routine results and results from about 40 chart-reviewed patients who meet the reference criteria.

It first fits the anchoredRI model, which uses the screened patients to pick out the reference group. If that fit fails its checks, it tries anchorRefine, a refineR-based fallback adjusted toward the screened patients and checked against them. If neither passes, it returns no interval and suggests what to do next.

Install in R Package help

In simulations, it returned an interval for 98–100% of datasets at every size tested.

What you need

  • Results from one group that can share a reference interval, with the same analyte, assay, age group and sex.
  • One result per patient.
  • A care-setting label for each routine result. You can use one or two settings.
  • Results from 40 screened patients who meet your reference criteria after chart review.
  • The assay’s reporting increment, if you know it. Otherwise the package infers it.

The simulations drew screened results separately from routine results, so the groups represented different people within each dataset. The routine dataset sizes tested were 1,000, 1,500, 5,000 and 50,000.

Read the limits in fit$limits. When no interval is available, fit$recommendation suggests obtaining at least 120 screened patients for a direct interval or verifying a suitable published interval with 20 screened patients.

Each method’s mean error is based on the datasets where it returned an interval. Checked refineR applies the same screened-patient check used for the fallback. Unchecked refineR uses the estimates before that check.

Install

Use R 4.1.0 or later. Both options build from source and need a C++17 compiler. On Windows, install the version of Rtools that matches your R release. On a Mac, install the Xcode Command Line Tools with xcode-select --install or use the tools included with Xcode. The package depends on ash and future.apply.

Five-line example

Put value and setting columns in routine.csv and a value column in screened.csv. Replace 0.1 with your assay’s reporting increment or omit that argument.

library(anchoredRI)
routine <- read.csv("routine.csv")
screened <- read.csv("screened.csv")$value
fit <- fit_anchored_ri(routine$value, routine$setting, screened, rounding_unit = 0.1)
fit[c("method", "status", "limits", "recommendation")]
