# Timing-pilot records

The release asset `task-h-records-pilot.tar` holds the 20 original per-dataset archives. Their original SHA-256 values appear in this directory. Each archive contains the models, sorted draw positions, both safeguard decisions and measured phase times for one pilot Index. The other eight release bundles contain the 1,420 subsequent datasets. [Task H data release](https://github.com/amromeo/amromeo.github.io/releases/tag/task-h-subsample-50000) · [Individual pilot checksums](SHA256SUMS)

To verify the original pilot evidence manifest, extract this asset at the root of the original pilot report directory, then run `sha256sum -c SHA256SUMS` there. [Original pilot report](../..)
