# Task H. Subsampling large routine datasets

**Status: proposed for review, 26 November 2026.** This study asks whether fifty fits to 5,000 routine observations give better reference limits than one fit to all 50,000, and whether a single weighted fit gives a similar result. Accuracy, coverage and sensitivity to the subsampling seed are separate outcomes. RIbench is a previously examined benchmark. This study is descriptive and specifies no new adoption threshold. Implementation and execution begin only after protocol approval. Study files belong in `anchoredRI/tools/subsample/` on `study/subsample`.

## Arm W. One weighted fit to the full routine vector

Fit the current anchoredRI mixture to all observed routine values with constant weight $q=5000/n$ and each of the 40 anchors with weight 1. On the original measurement scale, maximize

$$
\ell_W = q\sum_{i=1}^{n}\log\!\left(\sum_{k=1}^{K}\pi_k f_k(x_i)\right)
       +\sum_{j=1}^{40}\log f_1(a_j).
$$

Here $f_k$ includes the transform Jacobian and component 1 is the screened healthy component. Anchors contribute directly to component 1. Apply the same routine weights to the likelihood, Jacobian and derivatives, including at tied values. Fractional counts retain double precision. Keep the full-data rounding grid, search geometry, component constraints, eligible transformations and multistart procedure. Use the weighted joint mean and variance for the analytic one-component start. Divide by total weight 5,040 if the optimizer needs a mean objective. Rank candidates on the **summed** original-scale likelihood using $-2\ell_W+p\log(5000)$, where $p=2K+(K-1)$ for one routine setting, plus one parameter when fitting a log shift. Ordinary subsample fits keep the package’s own BIC, which uses $\log(5040)$. The safeguards use the observed full-data minimum and the original 40 anchors.

Return W's raw component-1 limits and its own two-check decision. W is a single weighted mixture fit. Also show the same W estimate under the two shared release rules below, labeled as alternative decisions, so differences in withholding can be separated from differences in the estimated limits. W's own safeguards and its raw endpoints stay visible in every row.

## Safeguards and release rules

On the full mixture, each subsample mixture and W, run both current anchoredRI checks. On the selected transform and shift, compare the Gaussian likelihood of the 40 anchors under their own maximum-likelihood mean and SD with that under fitted component 1. Use the package's nominal two-degree-of-freedom likelihood-ratio test and flag strictly at $p<0.01$. Independently flag a two-sided lower limit **strictly below the minimum routine value used in that fit**. Each subsample has its own observed minimum. CRP skips the lower-limit check. Record both flags, their intersection, p-value, minimum and technical errors. Either statistical flag declines one fit and a fit can cast only one vote. [Safeguard source](https://github.com/amromeo/amromeo.github.io/blob/fe8105ac6961f1b45bbfbe034648938f227c4726/anchoredRI/R/safeguard.R#L37-L73)

| Release rule for the same median | Decision |
| --- | --- |
| Full-data safeguard | Release when the unweighted full fit passes. Decline when that fit declines. An unavailable full fit or check gives a technical withholding. |
| Subsample majority | Decline when at least **26 of the 50** subsamples decline. A 25–25 split releases the estimate. Use all 50 attempted draws as the denominator. |

For the majority rule, if $v$ draws decline and $u$ are technically unresolved, decline if $v \ge 26$, release if $v+u \le 25$, and otherwise record technical withholding. A missing aggregate interval is always a technical nonreturn. Use the first-stage statuses for the primary median. For the public-package analysis, count the returned status: `reported` is a pass (including fallback releases), `declined` is a decline and `withheld` or an exception is technical. Save first-stage and fallback reasons even when the final status is inherited from the first stage. Do not run a new likelihood test on the endpoint medians. Report a cross-tabulation of both rules, including which rule released each discordant case.
