# Task H confirmation of the subsampling policy at N = 50,000

**Final decision, 27 November 2026.** The subsampling policy failed independent confirmation under both seed sets. It reported intervals on exactly the same datasets as the full package and increased mean endpoint error. Step c recovered none of three package nonreturns, giving insufficient evidence under the ten-recovery rule. Task H is closed. [Confirmation report](../results/confirmation-45912200495/REPORT.md) · [Protocol frozen before fitting](https://github.com/amromeo/amromeo.github.io/blob/140bd4372d9741c70c76999d2b47e998fac17e9d/anchoredRI/tools/subsample/confirmation/PROTOCOL.md)

**Approved for execution, 26 November 2026.** The question is whether replacing a full-data first-stage interval with the subsample median improves accuracy on datasets the package already serves, and whether the median can safely return an interval when the package withholds one. The comparator is the public anchoredRI 0.4.0 package, including its fallback. The policy, its routing order and its 50-draw median come from the RIbench review. This document fixes the confirmation cohort, scoring and success criteria before any Task H calculation on that cohort. ## Fit and route

Use the pinned Task H runtime (R 4.5.0), pooled routine setting, automatic transformation, up to five components, recorded h, and the same 40 anchors in all fits of a dataset. Run the public full-data fit once with both safeguards and ordinary package fallback enabled. Use mixture fitting seed 1, fallback fitter seed 123 and fallback PIT seed 38000000 + j for both banks. Retain its first-stage status and its actual final result. Each subsample uses only the same first-stage mixture and its two checks. These checks are the package’s anchor likelihood-ratio flag (p < 0.01) and its lower-limit flag (lower limit below that fit’s observed routine minimum). The median itself receives no additional model check. [Task H settings and runtime](../launch-full.json) · [Package entry point](https://github.com/amromeo/amromeo.github.io/blob/fe8105ac6961f1b45bbfbe034648938f227c4726/anchoredRI/R/fit_anchored_ri.R)

For each draw b from 1 through 50, sample 5,000 positions without replacement from the full vector, sort the positions and retain the original order. Use R’s Mersenne-Twister, Inversion and Rejection settings with `sample.int`. Bank A uses seed 100000000 + 100j + b. Sensitivity bank B uses 200000000 + 100j + b. Take the median of each raw endpoint over all draws with two finite, ordered endpoints, including statistically declined draws. Omit an unusable pair from both medians and report the contributor count. A majority approves when there are at most 25 declines even if every technically unresolved vote were a decline. At least 26 observed declines gives a decline. Otherwise the vote is unresolved. All 50 draws enter each vote. [Frozen aggregation](https://github.com/amromeo/amromeo.github.io/blob/558001e46480fa101900e3d658ac68cdf56ac2db/anchoredRI/tools/subsample/aggregate.R)

Apply these routes in order, once for each bank. The package comparator is the same full-data result in both banks.

| Step | Condition | Output |
|---|---|---|
| a | Full-data first stage passes both checks | Subsample median, regardless of the majority vote |
| b | First stage did not pass and the package returns a valid interval | Exact package interval |
| c | First stage did not pass, the package withholds, and the majority approves a usable median | Subsample median |
| d | Remaining assignments | No interval |

If step a has no usable median, record a technical nonreturn there and count the lost package return. Do not change its route after seeing the comparator or truth. Distinguish completed technical withholdings from statistical declines for the package and the individual draws. A missing execution record is incomplete work. Reconcile all assignments and draws before computing gates. Arm W and the three-component variants are closed. Their existing RIbench results remain available. ## Endpoints and success criteria

For each returned lower and upper endpoint x, compute the signed error z = Φ⁻¹(p) − Φ⁻¹(H(x)), using the known unrounded, support-corrected healthy CDF H and p = 0.025 or 0.975. Use the frozen Stage 2 numerical implementation. The dataset error d is the mean of the two absolute z values. A finite endpoint outside healthy support gets its boundary z, including infinite error. Count any endpoint with |z| > 5 as extreme. Report it also when the other endpoint is accurate. Both methods must have finite, ordered reported limits in measurement units. Flag invalid releases separately. [Synthetic truth and score](https://github.com/amromeo/anchorRefine/blob/c043917226b20929296b80cda53e0ae293968b42/stage2/generator.R)

The unit of analysis is one original j. Weight datasets equally. Define differences as policy minus package, so a negative difference favors the policy. Use bank A for the primary decisions, with unrounded point estimates and confidence bounds as specified below. Bank B measures seed sensitivity and cannot replace a failed bank A result.

| Claim | Criteria fixed for this confirmation |
|---|---|
| Accuracy on common returns | On the datasets where both return an interval, mean uncapped d must be lower for the policy than for the package overall. Within each of the two pathology strata, mean paired capped error (min(d, 5)) may increase by at most 0.02 on common returns. Require comparable returns in both strata. Report the three accuracy statements below individually. |
| Coverage and extremes | The policy must preserve every package return by j, release no invalid interval, and have no more released intervals with an extreme endpoint than the package overall or within either pathology stratum. |
| Error including nonreturns | Over all 1,440 assignments the mean of min(d, 5), scoring each nonreturn as 5, must be lower for the policy. This criterion is in addition to the common-return comparison. |
| Added coverage from step c | With at least 10 recoveries from package nonreturns, pass if mean uncapped d < 0.5 and zero recovered intervals have any extreme endpoint. Otherwise fail when there are at least 10 recoveries. With 0–9 recoveries record **insufficient evidence**, irrespective of their errors. List every observed extreme at any sample size. |

Report each supported statement for the policy versus the package on the identical jointly returned IDs:

- **Lower observed mean error** if the paired difference in mean uncapped d is strictly negative.
- **Improved accuracy** only if the entire cell-resampled two-sided 95% percentile interval for the paired difference in mean uncapped d lies below zero (upper bound < 0).
- **No worse** if the upper bound of the two-sided 95% cell-resampled interval for the overall paired difference in mean capped error is strictly below +0.02. Cap each dataset’s d at 5 before subtraction. This is a separate overall inference from the two prespecified pathology-stratum capped point-estimate gates.

Exactly zero or exactly +0.02 does not meet the respective strict confidence-bound criterion. Report the observed differences and intervals even when they cross the decision boundaries. If a bound cannot be estimated, record the corresponding inferential statement as unestablished. Compute both overall bounds on the same cell resamples.

For the uncapped common-return gate, compare the two method means on the identical set under extended-real arithmetic. A finite policy mean is lower than an infinite package mean. Two infinite means cannot establish improvement. Report the cases, the capped comparison and the finite-pair mean separately. Fewer than 10 recoveries preclude a pass for the complete policy even if every other row passes. Judge accuracy, coverage preservation and the all-assignment result separately, and reserve a claim for the complete four-step policy for a pass on all four rows. Report gate outcomes for B descriptively. These are criteria for this synthetic experiment at 50,000. Adopting a sample-size rule between 5,000 and 50,000 would require separate evidence.

Show the three healthy families separately. The power-0.5 family has no exact match among the three fitting transforms. Family differences are descriptive evidence about shape mismatch.

For step c give its denominator (all package nonreturns), number recovered, percentage, reasons the package withheld, numbers with a determined or unresolved vote, contributor and vote counts, mean and median d, maximum d, both signed endpoint errors, and every extreme. Report how often the same datasets are rescued under A and B, including individual gains and losses. Give a two-sided exact 95% binomial interval for the extreme rate among rescues, labeled descriptive for this factorial design. When few cases reach step c, report the resulting uncertainty even if its point-estimate criteria pass. If no rescue occurs, show zero and mark conditional rates and errors undefined. Give paired 95% percentile intervals for the common-return uncapped and capped error differences and the all-assignment score difference by resampling whole factorial cells (all eight replicates together, 2,000 resamples with NumPy PCG64 seed 37000000, both methods and both banks paired). List undefined bootstrap replicates. For claim decisions, use the unrounded percentile bounds. When undefined bootstrap draws occur, give their count and compute bounds on defined resamples, retaining signed infinities. Do not make an inferential claim for undefined observed differences or indeterminate bounds.
