# Subsampling at 50,000 routine results

We compared the full-data anchoredRI package with a policy that fitted 50 subsamples of 5,000 routine results using the same 40 screened patients. When the full-data first stage passed, the policy reported the median of each fitted limit across subsamples. Otherwise it retained the package fallback. If the package withheld an interval, step c could return the median when at least half the subsample fits passed. On the 1,440 RIbench datasets that informed the policy, mean absolute endpoint error on the healthy z scale fell from 0.1476 to 0.1308 on the 1,423 datasets both methods reported. Step c recovered 13 of the 17 package nonreturns, bringing the total to 1,436. [RIbench results](review/policy/REPORT.md)

On 1,440 independent synthetic datasets, both methods returned intervals for the same 1,437 datasets. Mean endpoint error rose from 0.0983 with the package to 0.1222 with subsampling. The paired increase was 0.0239 (95% confidence interval 0.0148 to 0.0338, resampling whole simulation cells). A second subsample seed set gave an increase of 0.0238 (0.0146 to 0.0338). Both upper bounds for capped error exceeded the prespecified noninferiority margin of 0.02. Step c recovered none of the three package nonreturns under either seed set, below the ten recoveries required to judge its accuracy. The subsampling policy failed confirmation, and the evidence for step c was insufficient. [Confirmation results](results/confirmation-45912200495/REPORT.md)
