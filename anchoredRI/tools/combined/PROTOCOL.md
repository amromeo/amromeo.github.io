# Task G protocol: anchoredRI with a checked fallback

**25 November 2026. Protocol for review.** The question is whether starting with safeguarded anchoredRI improves on the checked anchorRefine post-fit blend at each routine sample size. The independent test uses the 7,488 anchorRefine Stage 3 confirmation datasets. The earlier RIbench comparison motivated the study and will be reported separately. The amended protocol was approved on 25 November 2026. Stop again after presenting the results, before any package change.

## Methods fixed before fitting

Use the released anchoredRI 0.3.1 point fitter (Task E Arm B, up to five components) with its default safeguard enabled. Version 0.3.1 changed the large-dataset wording only. A reported fit returns its requested limits. A declined or technically withheld fit proceeds to the next method where specified. Retain the original status and reason at each step. Record an actual fitting error separately as a technical nonreturn eligible for fallback. A missing job or corrupt input is an incomplete run and must be resolved before scoring. [Package source](https://github.com/amromeo/amromeo.github.io/tree/07176a8cc46487ca9b4b427e2b3f917f185c22ae/anchoredRI)

| Method | Interval to return |
|---|---|
| A. Combined | Return anchoredRI if its safeguard passes. Otherwise try the Stage 3 post-fit blend (`t0.25`) at every N. Return the blend only if its own Stage 1 check passes. |
| B. Checked post-fit blend | Return `t0.25` only if its Stage 1 check passes. |
| C. Checked refineR (reference) | Return the Stage 3 `baseline` refineR fit only if its Stage 1 check passes. |

For a Stage 3 arm, use the exported native limits released for `panel = guidance`, `seed_kind = primary` and `status = keep`. Require all requested endpoints to be present and finite. A decline, fit failure, check failure, or unusable release returns no interval from that arm. If a sequence exhausts its options, return no interval and advise obtaining at least 120 screened patients for a direct interval or verifying a suitable published interval with 20 screened patients. Never substitute raw diagnostic limits. Keep the independent diagnostic panel, alternate PIT seed and scoring truth out of fitting and routing.

Report two descriptive variants and one co-primary order comparison. (1) Use A, but allow the blend fallback only when the routine vector contains at least 5,000 results. (2) Use A at every N with the checked Stage 3 weighted-search arm (`w1`) as fallback. (3) For co-primary method R, reverse A at every N: try the checked blend first and use safeguarded anchoredRI only if the blend does not return an interval. Each uses the same stored fits and its own arm-specific decisions. None participates in the success rule.

## Independent confirmation and audit

Use the frozen confirmation export from run 45463873162. All 7,488 datasets enter the denominator once per method. Nominal N is 1,000, 1,500, 5,000 or 50,000. Pathological fractions are 10%, 20%, 25%, 45% and 60%. The six disease patterns are left or right separated, left or right shoulder, bilateral separated, and overlapping. Keep the original replication counts, including the extra replicates for high-pathology shoulder and overlapping disease. Weight each dataset equally. 1. Verify the published SHA-256 hashes for the index, fit and check tables, shard ZIPs and primary RDS members. Restore the routine vector and the 40 guidance anchors in saved order. Verify both dataset hashes using the export's serialization convention. Join by phase and dataset ID `j`, then arm, panel and seed kind as applicable. Require one record per expected key and complete ID coverage.
2. On GitHub Actions, run one new anchoredRI point fit per confirmation dataset. Use one routine setting, the exported guidance panel and assay increment `h`, the two central 95% limits, automatic transform selection, default fit seed 1 and the package safeguard. Do not bootstrap or refit the Stage 3 arms. Record input hashes, requested probabilities, fit seed, selected model, rounding unit, optimizer status, raw and released endpoints, safeguard flags, decision and reason. Save the workflow revision, runner and R environment, package checksum and shard manifests. A retry must use the same inputs and cannot replace a fit because its result is unfavorable.
3. Before opening outcomes, select 749 unique confirmation IDs (10%, rounded up). Allocate them proportionally across N × pathological fraction × disease pattern by largest remainder, breaking allocation ties by ascending N, fraction and pattern name. Within each stratum take the lowest SHA-256 hashes of the UTF-8 string `TaskG-audit-v1:<j>` with decimal ID and no newline. Publish the ID list. In a separate Actions job, restore those inputs independently and repeat Arm B in the same pinned environment. Check input hashes, selected transform and component count, safeguard flags, reasons, status and route exactly. Compare raw and released endpoints with absolute tolerance 1e-10 and matching missingness. Reconstruct the exported primary checks and selected releases from the saved shard records for the audited IDs and verify the assembled methods and scores against those records. Publish discrepancies by ID. Resolve any unexplained mismatch or missing case before applying the success rule.

## Scoring, results and decision

Use Stage 3's native endpoint scoring. For confirmation, express each requested endpoint's error on the true healthy standard-normal scale using the frozen Stage 3 truth transformation and support-boundary convention. For RIbench, apply the published native scoring convention to each assembled method, including RIbench's method/analyte upper-zero rule across the cohort before stratifying. Cross-check standalone B and C against their published native scores. For each returned interval, cap each requested absolute endpoint z error at 5, then average the capped errors for that dataset. An out-of-support infinite z error contributes 5. Investigate missing scoring metadata or undefined scores before summarizing.

For each method show assigned and returned counts, share returned, mean capped error among returned intervals, and mean loss across all assigned datasets. Each nonreturn contributes exactly 5 to all-dataset loss. If none return, report returned-only error as undefined, share returned as zero and loss as 5. Give route counts for first method, fallback and no interval. Tabulate by N overall, by N and pathological fraction, by N and disease pattern or RIbench scenario, and by their joint strata; also show ≤20% and >20% pathology at each N.

**Success is decided only on independent confirmation.** For each of the four N values, compute the paired mean of dataset loss differences, A minus B. Overall, this difference must be strictly below zero. Among datasets with ≤20% pathology, it must be ≤0.02. Use unrounded values and show A loss, B loss, difference and pass/fail for both comparisons at every N. At each N also require paired mean capped error A minus B ≤0.02 on datasets where both methods return, overall and at ≤20% pathology. Show the paired denominator for every comparison. An empty common-return set cannot pass. All 16 conditions must pass. C, RIbench and variants 1 and 2 are descriptive. For co-primary A versus R, report paired loss and paired common-return error (A minus R), overall and at ≤20% pathology at each N, with denominators and 95% paired percentile intervals. Use 2,000 bootstrap replicates (seed 37000000), resampling confirmation datasets within design cells and RIbench parent scenarios (analyte and scenario) as clusters. Apply the same draws to both methods. Flag any positive A-minus-R loss at any N in either confirmation comparison and stop for review without changing the method. This comparison adds no success conditions. Present descriptive RIbench alongside confirmation for each headline contrast, marking N = 1,500 unavailable on RIbench. The confirmation healthy families follow anchorRefine’s Box-Cox design, including lambda = 0.5, which anchoredRI’s transform families do not represent exactly. Present the results, audit and any departures for review before proposing or making a package change.
