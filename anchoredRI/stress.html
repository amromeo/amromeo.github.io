Method & development

How the model works

What the screened sample tells us

A chart reviewer identifies children eligible for the reference population using clinical history. Each screened result helps estimate the center and spread of that population. Routine results can come from any of the fitted groups. Each setting gets its own estimated proportion in each group.

The package fits one, two and three bell-shaped groups of results, called Gaussian components. It uses the Bayesian information criterion (BIC) to select the model. The reference limits are the 2.5th and 97.5th percentiles of the reference group’s fitted distribution.

Why include outpatients alone?

Outpatients may contain a higher proportion of reference individuals. Filtering to clinic results can help, but it also reduces the number of observations. The demo fits the released refineR 2.0.0 to both cohorts with its default model and zero bootstrap replicates for the point estimates.

“Screened alone” uses the average and standard deviation of the chart-reviewed results to estimate the reference limits. The additional rows compare other ways of fitting the same data. Read the definition of each method.

How this project was developed

This project was fully AI-developed. A pediatric laboratory physician posed the question and directed the exploration. OpenAI ChatGPT designed and implemented the statistical prototype, simulations, R package, tests, documentation and website. The code uses conventional statistics and runs locally in R.

The first prototype identified a reference group from differences between settings. In simulations, that assumption struggled when disease prevalence was equal in both settings or disease shifted results toward both lower and higher values. The next version added independent screened observations and allowed an additional component.

What the simulation can establish

The generator uses one age group, one assay and a common reference distribution. Its bell-shaped groups of results match the model’s assumptions. All data are synthetic. No CHOP patient data were used, and clinical performance has yet to be established.

Forty is a study setting. Performance can change with the analyte, age, size of the reference sample, disease mixture and eligibility criteria. Clinical evaluation would require independent reference individuals, comparison of both reference limits and an assessment of how much the estimates vary between samples.

Simulation parameters and reproducibility

Reference-group aPTT-like results follow a normal distribution with mean 30 s and SD 3 s. Values are rounded to 0.1 s. The known reference limits are calculated before rounding. In the first scenario, the disease-associated distribution has mean 42 s and SD 4 s. In the other three scenarios, the distribution shifted upward has mean 36 s and SD 4.5 s. In the scenario with shifts in both directions, 55% of ward patients assigned to the disease group have a result from a distribution with mean 24 s and SD 2.5 s.

The screening option that also requires a result within 26–34 s starts with reference-group patients, then excludes those whose results fall outside that narrower range. This can bias the screened sample. For the same rule and dataset, each smaller screened cohort is included in the larger cohorts, up to 400 patients. Selecting zero screened patients leaves the routine-only methods and the fixed 120- and 400-patient screened-only comparisons available.

The 1,000-result design includes 250 clinic results. The refineR package flags input sizes below 1,000 for cautious interpretation. The additional two-component comparison fits the reference label with screened data at the same model size as the routine-only setting model.
