Help and definitions

What the patient groups, model labels and error summaries mean in this simulator.

The prepared-cohort comparison uses 5,000 routine patients, 200 bootstrap resamples, medianBS refineR estimates and nonparametric 120/400-person direct estimates. Its first run has one dataset per profile. Read the protocol and metrics.

Definitions of the clinic/ward mixtures refer to the earlier clinic/ward stress tests. Those examples use synthetic aPTT-like results in seconds. The two main terminology changes are “affected” → analyte-altering disease and “mean worst error” → average larger limit error.

The prepared-cohort comparison

Prepared cohort / physiological partition
A set of patients who can reasonably share a reference interval, with compatible assays and a stable measurement period. In these examples, age, sex and assay effects are held constant by construction. A real dataset needs those checks before fitting.
One dataset versus 200 bootstrap resamples
Each worked example starts with one generated group of patients. Bootstrapping repeatedly samples those patients with replacement and refits the method. It measures uncertainty within that example. It does not create 200 independent studies. The separate validation table uses 220 newly generated datasets to compare the original and updated anchoredRI point estimates.
Reference interval versus confidence interval
The reference interval aims to contain the central 95% of the reference population. A confidence interval describes uncertainty in an estimated endpoint. The chart shows a separate 95% confidence interval around the lower and upper reference limits.
medianBS
refineR's recommended bootstrap point estimate. The package chooses a representative model from the bootstrap fits, then calculates that model's reference limits. It does not simply take the median lower and median upper limit separately.
BoxCox and modBoxCox
refineR models a reference distribution that becomes approximately normal after a transformation. BoxCox estimates a power transformation. modBoxCox also allows a shift, which can help when a skewed distribution starts away from zero. The shifted example uses that model by design; clinical model choice needs fit review.
Estimated offset / shifted lognormal
A skewed distribution can start away from zero. For example, taking the log of a result minus 10 may fit its shape better than taking the log of the result itself. anchoredRI 0.2 estimates that offset from routine and screened observations while fitting the mixture. It is never given the simulation's true offset. The fitted offset is a statistical parameter, not necessarily a biological minimum.
Automatic family selection
The updated model compares normal, lognormal and shifted-lognormal fits, each with one to three components. The score rewards fit and penalizes extra parameters. It uses densities on the original measurement scale so the comparison is fair. Every bootstrap repeats this choice; the page reports how often each family was selected.
A one-component fit
The model treats the routine cohort and screened sample as one reference distribution. That can be appropriate for an essentially unaffected population. When disease overlaps the reference population, a single flexible curve can also absorb the disease results and distort the reference limits. In the shifted overlap validation scenario, the updated model chose one component in 11 of 20 datasets. Numerical convergence did not identify that problem.
Monte Carlo standard error
Uncertainty caused by using a finite number of simulated datasets. The validation CSV reports it for the average paired change in endpoint error. It is different from a confidence interval for a patient's reference limit, and does not address whether the simulation resembles clinical data.
Reference population inside
The percentage of the known simulated reference population falling within the fitted interval. The target is 95%. A value near 95% does not prove both endpoints are correct, so the table also reports endpoint error.
Larger limit error
Calculate the absolute error of each endpoint and report the larger one. For example, a lower limit 0.2 units too high and an upper limit 0.7 units too low give a larger limit error of 0.7. The prepared-cohort page reports one dataset; the stress page averages this error across repeated datasets.
Mean percentage error (MPE)
Express each endpoint's absolute error as a percentage of its true value, then average those percentages. The worked-example table averages the two endpoints of the selected dataset. The fresh-data table also averages across the 20 datasets in each scenario, as the original paper does across its simulations. Smaller values mean less error; the value for one dataset does not establish typical performance.
Empirical percentiles
Percentiles estimated directly from the ordered screened results, without assuming a normal distribution. The 120- and 400-person rows use the 2.5th and 97.5th percentiles. With 120 people, each tail is informed by only about three observations, so its estimated limit can vary substantially.

Patients and screening

Analyte-altering disease Previously “affected”

A disease or condition that changes the distribution of the target test. In the simulation, a patient assigned to this group has a result generated from a disease-associated distribution. Those results can overlap the reference distribution, so an individual result can still fall within the reference interval.

The disease percentages describe how patients are generated. They are separate from the percentage of measurements outside the reference limits.

Target analyte or test
The measurement whose reference interval is being estimated. Here it is a synthetic aPTT-like clotting time, expressed in seconds.
Reference population / reference-eligible patients
The population the reference interval is intended to describe. Here its results are generated from a distribution with mean 30 s and standard deviation 3 s. Clinical use would require eligibility criteria relevant to the test, patient population, age and assay. The earlier “healthy” label referred to this simulated reference group.
Case mix / disease prevalence
The proportions and types of patients in a dataset. “20% disease prevalence” gives each simulated patient a 20% chance of assignment to the analyte-altering disease group. The realized fraction varies between datasets.
Setting / clinic / outpatients / ward
Setting identifies where a patient receives care. The demo uses “clinic” for outpatients and “ward” for inpatients. Both settings contain reference-group patients and patients assigned to the disease group.
Routine results / unscreened results
Results from the full simulated clinical workload. They include both patient groups. For these results, the fitting method receives the measured value and setting. Group membership is unknown to the fitting method.
Screened patients / reference sample / anchors

Additional individuals designated as eligible for the reference population after clinical review. Their results tell the model which distribution represents that population. “Anchor” is the code’s name for a screened reference result.

In the demo, 1,000 routine results plus 40 screened patients means 1,040 different individuals. Each contributes one result. A clinical dataset assembled by reviewing routine patients would need to count each person’s result once.

Clinical-history screening / blinding
Eligibility is determined from clinical information while the reviewer is blinded to the target result. The simulation implements ideal screening by drawing all screened patients directly from the known reference population.
Screening by result / selection bias
The “History + result within 26–34 s” option begins with reference-group patients, then keeps those whose measurements fall within that narrower interval. This favors central values and can distort the estimated spread of the reference population. It demonstrates how using the target result to decide eligibility can affect an interval.
Independent patients / nested screened groups
The demo uses one result from each independent individual. For a fixed dataset and screening rule, smaller screened cohorts are included within larger ones, up to 400 patients. Every method compared at that setting receives the same routine results and, where applicable, the same screened results.

Reading the results

Reference interval / central 95%
The interval between the 2.5th and 97.5th percentiles of the reference population. About 2.5% of that population’s results fall below the lower limit and 2.5% above the upper limit.
Reference limits / endpoints / lower and upper limits
The two numbers that define the reference interval. Each method supplies an estimated lower limit and upper limit, shown in seconds.
Known reference interval / truth / ground truth
The interval calculated directly from the distribution used to generate reference patients. Here it is approximately 24.12–35.88 s. This known value lets us measure estimation error in a simulation.
Simulated dataset / replicate / draw
A newly generated set of patients under the same scenario and sample-size settings. There are 12 datasets for each scenario and routine sample size. Selecting “Dataset 1” shows one realization. Selecting “Average of 12 datasets” summarizes all 12.
Mean / average / average displayed limits
The sum of a set of numbers divided by how many numbers it contains. The lower limits and upper limits are averaged separately across the 12 datasets. The error summary is calculated within each dataset first, then averaged. It can therefore differ from the error you calculate using the two average displayed limits.
Absolute error in a reference limit
The distance between an estimated limit and its known value, expressed as a positive number or zero. An estimated upper limit 3 s above its known value has the same absolute error as one 3 s below it.
Shaded band / interval line / error bar
In the Limits view, the shaded band marks the known reference interval and each colored line spans a method’s estimated limits. In the Error view, the colored bar represents the larger limit error, averaged across datasets when that option is selected. Smaller errors indicate more accurate estimated limits.
Point estimate / confidence interval / bootstrap
A point estimate is the single reported estimate of a limit. A confidence interval describes uncertainty in that estimate. Bootstrap calculations repeatedly resample observations to assess variation. The prepared-cohort page uses 200 resamples per method, including full model and offset selection for updated anchoredRI. The earlier stress page displays point estimates and runs refineR without bootstrap resampling.
Accuracy / bias / precision
Accuracy describes how close estimates are to the known limits. Bias is a systematic tendency to estimate a limit too high or too low across repeated datasets. Precision describes how closely repeated estimates cluster together. The larger-limit error summary reflects both systematic error and variation between datasets.

How the error summary is calculated

Previously “worst error” and “mean worst error”

Larger limit error means the larger of the absolute errors in the lower and upper limits for one dataset. Average larger limit error is the average of those numbers across the 12 datasets.

Using the rounded reference interval 24.12–35.88 s, consider two illustrative datasets.

DatasetEstimated intervalLower-limit errorUpper-limit errorLarger error
A25.12–38.88 s1.00 s3.00 s3.00 s
B22.12–36.88 s2.00 s1.00 s2.00 s

Average larger limit error = (3.00 + 2.00) / 2 = 2.50 s.

The simulator applies the same calculation to 12 datasets. A displayed score of 0.47 s means that the less accurately estimated limit was 0.47 s from its known value on average across those datasets. This score summarizes errors in the reference limits. Individual patient results are the inputs to the interval estimation.

What each method uses

refineR · all results
The published refineR 2.0.0 algorithm fitted to every routine result from clinic and ward.
refineR · outpatients
The same published algorithm fitted to clinic results alone. This uses 250 results in the 1,000-result design and 1,000 results in the 4,000-result design.
anchoredRI
All routine results plus the clinically screened results. The reference distribution is identified using the screened patients. The model considers one, two and three components and selects one using BIC.
Screened alone · selected size
Uses just the screened results. The limits are the screened sample mean plus or minus approximately 1.96 times its standard deviation, assuming a Gaussian reference distribution. Read why the size of the screened sample matters.
Screened alone · 120 / Screened alone · 400
Direct reference intervals calculated from 120 or 400 screened patients using the same Gaussian method as the selected-size screened-only estimate. Both rows use the selected screening rule and are displayed alongside the joint model. Compare the sample sizes used by each method.
Settings alone
Uses all routine results and the clinic/ward labels, with a two-component mixture. It estimates a separate proportion in each component for each setting. It designates the component more prevalent in clinic as the candidate reference group.
Pooled mixture
Combines clinic and ward routine results when fitting a two-component mixture with one set of proportions. Afterwards, setting labels are used to identify the component enriched in clinic as the candidate reference group.
Anchored · two components
Uses all routine results and screened results, with the number of components fixed at two. Comparing this row with “Settings alone” helps assess the contribution of screened labels while keeping the same number of components. Comparing it with anchoredRI helps assess the effect of selecting the number of components.

Statistical terms

Distribution / Gaussian / normal / standard deviation
A distribution describes how results are spread across possible values. Gaussian and normal name the bell-shaped distribution used here. Its mean sets the center and its standard deviation (SD) describes the spread.
Component / mixture model
A component is one assumed distribution within the model. A mixture combines components in different proportions. The model can represent a reference distribution and additional distributions for disease-associated results. A fitted component’s clinical interpretation depends on the screening and model assumptions.
Mixture proportion / weight / fraction
The estimated proportion of routine patients assigned to each component in a setting. The components’ shapes are shared between clinic and ward. Their proportions can differ. The weights within each setting sum to one.
Enrichment / enrichment gap
A group is enriched in clinic when its estimated proportion is higher in clinic than on the ward. The enrichment gap is the absolute difference between those estimated proportions. The routine-only “Settings alone” and “Pooled mixture” methods use this assumption to name a candidate reference component.
Likelihood / fitting / maximum likelihood
Likelihood measures how well a proposed set of distributions accounts for the observed values under the model. Fitting adjusts the component centers, spreads and proportions to find values with high likelihood. Each screened result contributes to the designated reference component.
Bayesian information criterion (BIC)
A score that balances fit to the observed data against the number of fitted parameters. anchoredRI selects the lowest BIC among its one-, two- and three-component models. Automatic selection also compares distribution families and penalizes the extra offset parameter. This score is a practical selection rule; a low score does not prove the model is correct.
Tails / one-sided and two-sided disease effects
The tails are the lower and upper ends of a distribution. An upward disease shift generates higher results on average. A downward shift generates lower results on average. The scenario with shifts in both directions uses two disease-associated distributions on the ward.
Identity scale / log transformation / shifted log
Identity fits the measured values directly. Log fits after taking logarithms of positive results. Shifted log first subtracts an estimated offset, then takes logarithms. All reference limits are converted back to the original units. The earlier stress examples use identity. The prepared-cohort page compares the original identity/log approach with automatic selection in version 0.2.
Random seed / reproducibility
A seed fixes the sequence of random numbers used to generate a dataset. The same scenario, dataset number and sample-size settings reproduce the same simulated observations. Website controls select fits that were calculated in R in advance.

Fitting warnings and interpretation

Parameter bounds / numerical fitting limits
The optimizer is given allowable ranges for component means, spreads and proportions to regularize the fit. The warning appears when a fitted parameter reaches one of those bounds. “anchoredRI (6/12)” means this occurred in six of the twelve displayed fits. The fitted result warrants inspection because an imposed constraint may influence it.
Optimizer / convergence / starting points
The optimizer is the numerical procedure that adjusts the model parameters. Convergence means it met its numerical stopping rule. The fitter tries several starting points and chooses a converged fit with the highest likelihood. Clinical interpretation still depends on whether the model describes the intended population.
Simulation evidence / clinical validation
The comparisons show how the methods behave under the stated assumptions. Reference labels are perfect, and both services share the same reference distribution. The shifted example falls outside the original anchoredRI family; the updated family can represent it. Clinical validation would require independent reference individuals and assessment of both estimated limits in the intended patient population.
